# HW-14 — Тестирование классов `Product` и `Category`

## Описание проекта

Этот проект демонстрирует реализацию простых классов `Product` и `Category` для хранения информации о товарах и категориях. Также добавлены тесты для проверки корректности работы классов, а также отчет о покрытии кода тестами.

Проект создан как учебное задание и может быть использован как шаблон для моделирования предметной области интернет-магазина.

---

## Возможности

- Хранение информации о продуктах: название, описание, цена, количество на складе.
- Группировка продуктов по категориям.
- Подсчёт общего числа категорий и товаров в них.

---

## Установка

Для разработки и запуска тестов используется Poetry.

### 1. Клонируйте репозиторий:

```bash
git clone https://github.com/SabaiDeeMai/hw-14.git
cd hw-14
```

### 2. Установите зависимости:

```bash
poetry install
```

---

## Запуск программы

Чтобы запустить программу (вывод информации о продуктах и категориях):

```bash
python src/main.py
```

---

## Запуск тестов

Для запуска тестов используйте команду:

```bash
poetry run pytest tests/test_main.py -v
```

---

## Покрытие кода тестами

Вы можете сгенерировать отчет о покрытии кода:

```bash
poetry run coverage run -m pytest tests/test_main.py
poetry run coverage report -m
```

Для графического отчёта:

```bash
poetry run coverage html
```

Откройте файл `htmlcov/index.html` в браузере.
